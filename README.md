## 📌 Project Overview

This project focuses on analysing Instagram performance data for Sugar Cosmetics to understand audience reach, engagement, content trends, and campaign performance.

An interactive dashboard was developed using Tableau to transform data into meaningful visual insights and support data-driven decision-making.

The dashboard combines key performance indicators (KPIs), trend analysis, hashtag analysis, and comparisons of post types and campaign categories in a single view.

## 🎯 Project Objectives

- Analyse key Instagram performance indicators.
- Understand weekly likes and monthly posting trends.
- Explore hashtag performance based on likes.
- Compare likes across different post types.
- Analyse likes across campaign categories.
- Build an interactive Tableau dashboard.
- Provide recommendations for improving social media strategy.

- Total Reach
