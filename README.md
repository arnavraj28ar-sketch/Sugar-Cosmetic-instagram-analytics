## 📌 Project Overview

This project focuses on analysing Instagram performance data for Sugar Cosmetics to understand audience reach, engagement, content trends, and campaign performance.

An interactive dashboard was developed using Tableau to transform raw data into meaningful visual insights and support data-driven decision-making.

The dashboard combines key performance indicators (KPIs), trend analysis, hashtag analysis, and comparisons of post types and campaign categories in a single view.

## 🎯 Project Objectives

- Analyse key Instagram performance indicators.
- Understand weekly likes and monthly posting trends.
- Explore hashtag performance based on likes.
- Compare likes across different post types.
- Analyse likes across campaign categories.
- Develop an interactive Tableau dashboard.
- Provide recommendations to improve social media strategy.

## 🛠️ Tools & Technologies

- **Tableau:** Interactive dashboard development and data visualization.
- **Data Analysis:** Exploring trends and comparing performance metrics.
- **Data Visualization:** Presenting information through charts and KPI cards.

## 📊 Key Performance Indicators (KPIs)

The dashboard includes the following KPIs:

| KPI | Description |
|---|---|
| Total Follows | Total follows recorded in the dataset |
| Total Reach | Reach metric represented in the dataset |
| Total Likes | Total likes recorded in the dataset |
| Total Comments | Total comments recorded in the dataset |

These KPIs provide a high-level overview of Instagram performance.

## 📈 Dashboard Visualizations

### 1. Weekly Likes Trend
Displays weekly likes patterns to help explore changes in audience engagement over time.

### 2. Monthly Posting Trend
Shows posting activity across different months and helps analyse publishing patterns.

### 3. Top Hashtags by Likes
Compares hashtags based on the likes associated with them.

### 4. Likes by Post Type
Compares likes across different post types to explore content performance.

### 5. Likes by Campaign Type
Shows differences in likes across campaign categories.

## 🎛️ Interactive Filters

The dashboard includes three interactive filters:

- **Post Type:** Explore data for different post types.
- **Campaign Type:** Analyse performance across campaign categories.
- **Month of Post Date:** Filter the analysis by month.

These filters allow users to explore the data according to their requirements.

## 🔍 Key Analytical Observations

The dashboard helps explore:

- Weekly patterns in likes.
- Monthly posting activity.
- Differences in likes associated with hashtags.
- Performance comparisons across post types.
- Differences in likes across campaign categories.

These observations can help identify patterns and areas for further analysis.

## 💡 Recommendations

Based on the analysis available in the dashboard, the following recommendations can be considered:

- **Content Strategy:** Test different content formats and compare their performance.
- **Posting Schedule:** Review posting activity to improve content planning.
- **Hashtag Strategy:** Evaluate hashtag performance and test relevant alternatives.
- **Campaign Performance:** Compare campaign categories to understand differences in audience response.
- **Continuous Monitoring:** Track KPIs regularly to evaluate performance over time.
- **Data-Driven Decisions:** Use analytical findings to support future social media planning.

These recommendations should be evaluated through further analysis and ongoing performance monitoring.
